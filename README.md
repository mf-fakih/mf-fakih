## `06` — Coding Challenge 🎮

<details>
<summary><b>🎯 LEVEL 01 — Guess the Output</b></summary>

**What will this JavaScript code print?**

```javascript
let x = 10;
let y = 5;

console.log(x + y * 2);
```

<details>
<summary>🔓 Reveal Answer</summary>

```javascript
20
```

Because multiplication happens before addition:

`10 + (5 × 2) = 20`

</details>
</details>

<details>
<summary><b>🎯 LEVEL 02 — Find the Bug</b></summary>

Can you find the problem?

```javascript
const name = "Fakhril";

name = "Developer";

console.log(name);
```

<details>
<summary>🔓 Reveal Answer</summary>

The problem is using `const` and then trying to reassign its value.

Use `let` if you want to change the variable.

</details>
</details>

<details>
<summary><b>🎯 LEVEL 03 — Final Boss</b></summary>

<summary>🔓 Reveal Answer</summary>

```javascript

```

In JavaScript, arrays have the type `"object"`.
